# Security Policy / Güvenlik

Please **do not** open public issues for security vulnerabilities.

Report them privately via GitHub: **Security → Report a vulnerability** (Security Advisories) on
https://github.com/ybrzcn/Personal-Finance-Tracker. Include steps to reproduce and the affected version.

Güvenlik açıklarını lütfen herkese açık issue olarak değil, GitHub'daki **Security → Report a vulnerability**
bölümünden özel olarak bildirin.
